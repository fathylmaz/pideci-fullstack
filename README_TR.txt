PIDECI - 45 URUN GORSEL PAKETI
==============================

Bu pakette ekrandaki 45 ürünün tamamına karşılık gelen ayrı adlandırılmış WebP dosyaları ve ana sayfa için 1920 x 900 görsel vardır.

Uygulama dosyaları: web/images/v2/*.webp
İnsan tarafından okunabilir adlar: URUN_GORSELLERI/<kategori>/<urun adi>.webp
Dosya eşleştirmesi: URUN_GORSEL_LISTESI.csv

Kurulum: Çalışan sunucuyu CTRL+C ile durdurun.
1) C:\VS CODE PROJE\Pideci-Sitesi\web\images\v2 klasörünü yedekleyin.
2) ZIP'in içeriğini mevcut C:\VS CODE PROJE\Pideci-Sitesi klasörüne çıkarın.
3) BASLAT_WINDOWS.bat ile başlatıp Ctrl+F5 yapın.

Bu görseller yalnızca ürün tanıtımı amacıyla AI kullanılarak hazırlanmış ÖRNEK görsellerdir. İstendiğinde yöneticiden gerçek fotoğraflar yüklenebilir.
Bazı fotoğraflar doğrudan yüksek çözünürlükte üretildi; geri kalanlar üretim kolajından ayrılıp 1200 x 780'e büyütüldü ve özgün HD fotoğraflarla aynı doğal detay seviyesine sahip değildir. Detaylar CSV'de belirtilmiştir.

Ürün adı, fiyat, açıklama, stok, kullanıcılar, siparişler, yönetici şifresi ve veritabanına dokunulmaz.
Yöneticiden özel bir görsel yüklediyseniz onun URL'si değişmez; bu paket yalnızca demo ürün dosyalarını günceller.
